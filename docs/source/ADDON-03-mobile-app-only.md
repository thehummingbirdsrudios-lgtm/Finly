**ADD-ON — MOBILE APP ONLY**

Build this as a **professional Android mobile app**, not a web UI adapted to mobile.

Follow proper mobile engineering principles: **smooth UI, fast startup, no lag/jank/ANR, low memory/battery usage, offline support, responsive touch UI, lifecycle-safe code, efficient state management, async/background processing, caching, pagination, optimized DB/API calls, crash prevention, graceful error handling, and older Android compatibility**.

Design every screen for **small-screen usability, minimum clicks, easy navigation, fast search, clear actions, and real-world daily use**.

Use professional **architecture, clean code, SOLID, modularity, security, testing, performance profiling, and maintainability** throughout.

**Build → Run → Test → Profile → Fix → Retest** every major feature before considering it complete.
