**ADD-ON — BEST-IN-CLASS UI/UX + DYNAMIC MOTION & VISUAL DESIGN**

Make **UI/UX and visual design a core product feature**, not an afterthought.

Create a **simple, clean, premium, highly intuitive, visually polished** interface where users can understand and complete tasks quickly with minimal clicks, while the underlying system remains powerful and configurable.

Use **beautiful visual decoration, premium composition, subtle depth, tasteful shadows, cards, surfaces, gradients, illustrations, icons, backgrounds, dividers, highlights, empty-state visuals, and other decorative elements** where appropriate.

Decoration must improve the product's **visual hierarchy, brand identity, clarity, and overall feel**. Do not add decoration randomly or overcrowd financial information.

Use **dynamic, context-aware animations and transitions** instead of repetitive/default animations.

Give different interactions their own appropriate motion language:

**page navigation + tab changes + navbar selection + cards + buttons + forms + search + filters + bottom sheets + dialogs + success + error + loading + notifications + financial state changes + expandable sections + gestures**

Use **custom-designed transitions, animations, and micro-interactions** where they improve clarity or delight.

Examples:

**successful transaction → satisfying success motion**  
**blocked/invalid transaction → clear corrective feedback motion**  
**search/filter → smooth result transformation**  
**navigation → contextual page transition**  
**expand/collapse → natural motion**  
**saved/updated record → immediate visual confirmation**  
**sync → clear progress/state animation**

Do not use the same animation everywhere. **Choose the most appropriate animation for the user's action and context.**

Maintain excellent:

**spacing + hierarchy + typography + alignment + touch targets + information density + visual consistency + accessibility**

Use the centralized design system for all components, while allowing **purposeful component-specific visuals, decoration, motion, and interaction patterns**.

The UI must feel **alive, responsive, premium, polished, and enjoyable**, while never becoming flashy, confusing, slow, or distracting.

Always prioritize:

**CLARITY → USABILITY → SPEED → CONSISTENCY → FEEDBACK → VISUAL QUALITY → DELIGHT**

Study the actual product workflow before designing screens and interactions. Use decoration and animation only where they strengthen the experience.

The final result should feel like a **carefully designed premium financial product with its own distinctive visual and interaction language**, not a generic Flutter/Material application or a plain CRUD interface.
