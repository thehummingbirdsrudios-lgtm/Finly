**ADD-ON — BEST PREMIUM THEME**

Choose the **best visual theme for this financial app** based on the product, users, readability, trust, accessibility, and premium feel.

Do not blindly use a default Flutter/Material theme. Create a **distinctive, professional Finly theme** with a strong visual identity.

The theme must include a complete design system for:

**primary/secondary colors + background + surfaces + typography + icons + cards + borders + shadows + buttons + inputs + status colors + charts + navigation + dark/light mode**

Keep financial information highly readable and make important states instantly understandable without relying only on color.

The theme should feel:

**PREMIUM + TRUSTWORTHY + MODERN + CLEAN + SIMPLE + PROFESSIONAL**

Keep all theme values centralized and configurable so the visual identity can be changed later without redesigning individual screens.
